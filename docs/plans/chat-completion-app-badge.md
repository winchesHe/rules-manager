# Chat 完成角标

## 改动范围

- Native Chat 的 Assistant Turn 成功落盘后，通知主进程角标计数器。
- 应用不在前台时，每完成一轮累计一次；两轮依次显示 `1`、`2`。
- 应用重新获得焦点时清零角标；应用在前台完成的轮次不产生未读角标。
- Rules 发起的 Native Chat 只在整次生成成功后累计一次；失败路径不累计。
- 角标是进程内 UI 状态，不写入 ChatStore、数据库或对话文件。

## 观察点与验收标准

- 后台完成第一轮后，Dock / 系统应用图标显示 `1`。
- 未回到应用前再完成一轮，角标显示 `2`。
- 聚焦应用后角标消失，下一次后台完成重新从 `1` 开始。
- 前台完成、Provider 失败或角标 API 不可用时，不产生错误的未读数，也不改变 Chat 成功/失败结果。

## 验证方式

- 单元测试覆盖累计、前台忽略、聚焦清零和系统 API 异常隔离。
- Native Chat Controller 测试覆盖成功完成回调与失败不回调。
- App 全量测试、production build、`git diff --check`。
- 可运行 Electron 时，使用真实后台完成对话验证 Dock 角标和聚焦清零。
