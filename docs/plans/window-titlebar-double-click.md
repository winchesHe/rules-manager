# 顶部边栏双击缩放

## 改动范围

- 双击应用最顶部现有拖拽区域，在最大化与原窗口尺寸之间切换。
- 继续保留顶部单击拖动窗口能力；交互按钮所在的 `no-drag` 区域不触发缩放。
- 只操作发起 IPC 的 BrowserWindow，不依赖全局主窗口引用。
- 全屏状态不参与最大化切换，避免退出或改变用户主动进入的全屏模式。

## 观察点与验收标准

- 普通窗口双击顶部空白边栏后最大化，但不进入系统全屏。
- 再次双击同一区域后恢复双击前的窗口大小与位置。
- 顶部区域仍可单击拖动；Chat Header 等顶部按钮保持可点击。
- Settings、Chat、Rules 等页面共享同一行为。

## 验证方式

- 单元测试覆盖普通窗口最大化、已最大化窗口还原、全屏不处理。
- 布局合同测试覆盖拖拽层双击事件、IPC 注册与来源窗口解析。
- App 全量测试、production build、`git diff --check`。
- 真实 Electron 中双击顶部边栏，视觉确认最大化与恢复尺寸。
