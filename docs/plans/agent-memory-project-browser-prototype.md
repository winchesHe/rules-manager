# Agent Memory 项目浏览原型

## 改动范围

- 新增一个独立 HTML 原型，不修改真实 Renderer、IPC 或 Memory 文件。
- Agent Memory 提供「按项目」和「全部来源」两个视图。
- 「按项目」按真实工作目录归组 Claude 与 Codex 来源，无法确认项目路径的 Claude 来源进入「待关联」。
- 点击项目进入独立详情，分别查看汇总、Claude 和 Codex 内容来源。
- 支持项目搜索、Agent 筛选、刷新反馈和窄屏布局。

## 观察点

- 用户能否快速回答「某个项目有哪些 Memory」。
- 用户能否理解 Codex 项目 Memory 是从统一 `MEMORY.md` 派生的逻辑视图。
- 用户能否区分项目归组和物理文件合并。
- Claude 无可靠项目路径时是否明确进入待关联，而不是错误归组。
- 全部来源视图是否保留物理来源和派生范围之间的层级。

## 验证方式

- 使用桌面浏览器打开原型，截图检查 1440×900 视口下的页面层级、密度和首屏信息完整性。
- 切换「按项目 / 全部来源」，验证内容、计数与辅助说明同步变化。
- 搜索和 Agent 筛选后，验证项目列表与空状态。
- 打开项目详情，验证返回、来源 tab 和文件边界说明。
- 使用 390×844 视口检查无横向溢出，顶部工具栏和项目行正常折行。
- 检查浏览器控制台无 error。

## 验收标准

- 单个 HTML 文件可直接打开并完成全部演示交互。
- 默认进入「按项目」，项目列表中 Claude 与 Codex 归在同一真实路径下。
- 「全部来源」按 Claude 项目文件、Codex 本机合并文件、Codex 派生项目范围分组。
- 项目详情不伪装成新的合并文件，每段内容保留来源路径或匹配条件。
- 桌面与窄屏布局均可用，视觉贴合现有 HeroUI + Tailwind 产品界面。
