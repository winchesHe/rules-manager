# Agent Dashboard 侧栏主导航内容横向留白

## 范围

- 恢复侧栏「工作区」分组中 Scan / Projects / Chat 三个主导航条目原有的垂直间距。
- 增加展开态图标、文字与选中 / 悬浮背景左边缘之间的横向内边距。
- 保持背景范围、条目高度、图标文字间距、分组间距与侧栏收起行为不变。

## 观察点

- 图标与选中 / 悬浮背景左边缘之间有 16px 留白，不再显得贴边。
- 三个主导航条目的内容横向对齐一致，选中 Scan / Projects / Chat 时布局不跳动。
- 主导航恢复原有 2px 垂直间距。
- 展开态与收起态都不出现横向溢出或对齐回归。

## 验证方式

- 运行 App Shell 定向测试，确认导航结构与侧栏折叠合同不变。
- 运行 Electron production build。
- 在真实 Electron 中分别检查展开态、收起态以及 Projects 选中态。
- 运行 `git diff --check`。
