# 项目 Memory 发布卡片合并

## 目标

将已接受规则发布页右栏中的 Claude Project Memory 与 Codex 项目 Memory 合并到同一个「发布到项目 Memory」卡片中，减少同类入口的视觉割裂。

## 改动范围

- 只调整 Renderer 的展示层级与中英文文案。
- Claude 与 Codex 继续使用各自独立的目标选择器、状态提示和发布按钮。
- 不修改目标发现、发布协议、并发校验、默认选择或成功反馈逻辑。

## 验证方式

1. 更新源码布局契约测试，确认一个外层卡片同时包含两类 Memory 目标与两套独立操作。
2. 执行 App 定向测试、完整测试和 production build。
3. 在真实 Electron 发布页检查卡片层级、分区边界、滚动与窄栏内容展示，不触发发布写操作。

## 验收标准

- 右栏只展示一张项目 Memory 外层卡片。
- 卡片内清楚区分 Claude Project Memory 与 Codex 项目 Memory。
- 两类目标选择、禁用态、加载态与发布动作保持原行为。
- 页面无横向溢出，右栏独立滚动和窄屏回退不受影响。
