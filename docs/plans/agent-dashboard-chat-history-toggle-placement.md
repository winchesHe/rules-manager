# Agent Dashboard Chat History 开关下移

## 范围

- 保留全局侧栏按钮在右侧主界面左上角。
- 把 Chat History 开关从 Chat 顶栏下移到「对话历史」标题行；历史栏关闭时在 Chat 内容区左上角提供恢复入口。
- 不修改历史数据、筛选、会话生命周期、侧栏宽度、主题或其他页面。

## 观察点

- 全局侧栏按钮和 Chat History 开关此前占用同一顶栏坐标，产生视觉与点击热区重叠。
- History 开关属于历史栏自身，把它放入对应 Pane 的标题行比移动全局 App Shell 控件更符合归属关系。
- History 关闭后 Pane 宽度为 0，必须在内容区提供独立恢复入口，不能形成不可逆的隐藏状态。

## 验证方式

- 合同测试锁定 History 开关先于「对话历史」标题、Chat Header 左侧预留、关闭态恢复按钮及全局按钮位置。
- App 全量测试与 production build 验证历史栏状态、侧栏折叠和其他 Chat 行为不变。
- Computer Use 检查 History 展开、关闭、恢复，以及全局侧栏展开/收起时两个按钮的视觉与点击边界。

## 验收标准

- Chat 顶栏不再显示 History 开关，全局侧栏按钮与当前标题不重叠。
- History 展开时，开关位于「对话历史」标题左侧；点击后关闭 History。
- History 关闭时，内容区左上角出现恢复按钮；点击后重新打开 History。
- 两个按钮在展开/收起侧栏及浅色/深色主题下均保持独立热区。
