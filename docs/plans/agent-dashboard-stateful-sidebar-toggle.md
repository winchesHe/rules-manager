# Agent Dashboard 状态式侧栏开关

## 范围

- 移除普通页面、Chat 和 Settings Header 内的全局侧栏开关。
- 展开状态将收起按钮固定在主侧栏的 macOS 标题栏行，使用带左向收起标识的侧栏图标，与交通灯同轴并按
  Codex 的间距排列；品牌区从标题栏下方开始。
- 收起状态将展开按钮放在主侧栏底部，位于设置与主题操作区上方。
- 不修改侧栏宽度、导航、主题、页面标题、内容布局或 Chat History。

## 观察点

- 全局侧栏开关属于 App Shell，不应跟随不同页面的 Header 结构重复出现。
- 展开状态下按钮与 Codex 一样进入原生窗口标题栏语境，同时仍完整属于侧栏。
- 标题栏按钮必须脱离侧栏内容流并高于全局窗口拖拽层，避免热区失效；侧栏内容统一为标题栏保留固定高度。
- 收起状态下主导航只剩图标，恢复入口放在侧栏底部可以避开高频导航，并与设置、主题形成稳定控制区。

## 验证方式

- App Shell 合同测试锁定展开态标题栏、收起态底部两个互斥位置及其相对 DOM 顺序。
- 窗口拖拽合同锁定展开态按钮的绝对坐标、左向收起图标、`no-drag` 语义和高于拖拽层的层级。
- 页面布局与 Chat 合同禁止 `PageHeader`、Chat Header、Settings Header 重新承载全局侧栏开关。
- Computer Use 检查 Scan、Chat、Settings，覆盖侧栏展开/收起和浅色/深色主题。
- App 全量测试和 production build 验证无行为回归。

## 验收标准

- 展开状态只有侧栏标题栏显示收起按钮，其图标、水平轴线、交通灯间距和标题栏高度与 Codex 参考一致。
- 收起状态只有侧栏底部显示展开按钮，并位于设置与主题操作区上方。
- 页面内容区不再出现全局侧栏按钮或为其预留空白。
- 两种按钮热区完整，切换后位置和图标同步更新。
