# Agent Dashboard 常亮窗口交通灯

## 范围

- macOS 隐藏原生红黄绿窗口按钮，使用相同尺寸、颜色、坐标和功能的自绘控件替代。
- 红、黄、绿按钮分别执行关闭、最小化和窗口缩放。
- 三颗按钮不跟随窗口焦点变灰，在浅色和深色主题下保持常亮。
- 不修改侧栏按钮、标题栏高度、窗口拖拽区、页面布局或主题 token。

## 观察点

- macOS 原生交通灯由系统控制失焦状态，Electron 没有强制常亮配置，因此必须隐藏原生按钮后自绘。
- 自绘按钮中心保持在 22px、42px、62px，侧栏按钮中心保持 105px，延续与 Codex 对齐后的间距关系。
- 控件层必须高于全局拖拽层并声明 `no-drag`，否则按钮会显示但无法点击。

## 验证方式

- 窗口行为单元测试覆盖关闭与最小化动作，既有测试继续覆盖缩放动作。
- 窗口布局合同锁定原生按钮隐藏、自绘控件坐标、尺寸、颜色、层级、IPC 和无障碍名称。
- Computer Use 检查聚焦、失焦、浅色、深色，并实际操作最小化、缩放和关闭。
- App 与 Core 全量测试、production build 和 `git diff --check` 验证回归。

## 验收标准

- 窗口聚焦或失焦时，三颗按钮都保持红、黄、绿，不变灰。
- 三颗按钮位置和尺寸不改变，与侧栏按钮保持既有对齐关系。
- 关闭、最小化和缩放动作均可用，拖拽标题栏不受影响。
