# Agent Dashboard 可折叠侧栏

## 目标

为固定高度 App Shell 增加侧栏收起能力，在扩大主工作区的同时保留高频导航、设置和主题切换入口。

## 范围

- 侧栏默认保持现有 `11.125rem` 展开宽度，用户点击 macOS 标题栏行、紧邻交通灯的收起按钮后收起为
  `3.5rem` 图标栏；该按钮脱离内容流，不改变品牌区纵向位置。收起后，
  展开按钮移动到侧栏底部的设置与主题操作区上方。按钮在两种状态下均完整位于侧栏内，不进入页面 Header，
  不跨压侧栏边框；Chat 的
  History 开关下移到历史栏自身标题行，避免占用同一位置。
- 收起状态保留品牌图标、Scan / Projects / Chat、规则管理 / Agent 上下文、Settings 和主题按钮。
- Workspace 与 Settings 图标继续直接导航；知识库图标在收起状态下先展开侧栏，以便用户选择具体叶子页面。
- 收起时隐藏分组标题、文字标签、知识库叶子与 Disclosure 箭头，图标按钮提供 `aria-label` 与原生提示。
- 展开/收起使用 200ms 网格列宽过渡，并遵循 reduced motion；按钮使用侧栏内的标准 Button 热区。
- 本轮状态只在当前 App 运行期间保留，不新增持久化设置。

## 观察点与验证方式

| 观察点 | 验证方式 |
|---|---|
| 展开宽度、收起图标栏宽度与主内容自适应正确 | App Shell 合同测试 + Electron 视觉检查 |
| 展开态标题栏收起按钮和收起态底部展开按钮始终可点击，不遮挡品牌、导航、设置或主题操作 | 合同测试 + Electron 交互检查 |
| 收起后 Workspace、Settings 与主题按钮仍可操作 | Electron 交互检查 + App 全量测试 |
| 点击收起状态的知识库图标会恢复侧栏并展开目标分组 | 状态合同测试 + Electron 交互检查 |
| 深浅主题下边缘按钮、边框、选中态对比清楚 | Electron 双主题视觉检查 |
| Chat / Settings 固定 viewport 和窗口拖拽行为不回归 | 既有布局/拖拽测试 + production build |

## 不在本轮

- 不把折叠状态写入 localStorage 或数据库。
- 不修改主页面、Rules 页面、Settings 页面或主题 token。
- 不改变窗口尺寸、侧栏默认展开状态或现有导航路由。
