# Agent Dashboard 侧栏按钮与 Chat 顶栏重叠修正

## 范围

- 把全局侧栏折叠按钮从主界面左上角移入左侧栏底部操作区。
- 不修改 Chat 历史按钮、侧栏宽度、导航行为、主题或业务页面。

## 观察点

- 全局按钮以绝对定位占用主界面左上角；Chat 同一位置已有对话历史开关，两者在 Chat 页面发生视觉与热区重叠。
- 页面级浮层无法保证未来不会继续与 Scan、Settings 或新增页面的顶栏操作冲突。

## 验证方式

- App Shell 合同测试锁定折叠按钮位于 `<main>` 之前，并移除 `sidebar-collapse-toggle` 绝对定位样式。
- App 全量测试与 production build 验证导航及折叠行为不变。
- Computer Use 检查 Chat 展开侧栏、收起侧栏、重新展开，以及品牌完整性和 Scan / Settings 顶部布局。

## 验收标准

- 展开时设置、收起、主题切换在侧栏底部并列；收起时三个操作纵向保留，品牌标题不被压缩。
- Chat 历史按钮保持独立，不与全局侧栏按钮发生视觉或点击热区重叠。
- 主界面所有页面不再为全局侧栏按钮预留或覆盖左上角空间。
