# T3 Code 会话搜索

1. 实现只读 T3 v2 数据访问层。以线程 ID 枚举未删除线程，在同一 SQLite 快照内读取线程、原生会话关联和消息，区分真人输入和 Agent 代发。用合成库测多关联、缺失线程和损坏数据，用本机线程核对标题与消息来源。
2. 将数据源接入 scan、项目分类、查询与实时读取。扫描默认 T3 目录，明确处理旧版表的覆盖范围。用 provider 与原生 ID 匹配别名，保留多个原生会话的独立身份，验证不带来源筛选、按 T3 来源筛选和按 provider 筛选的行为。扫描缓存仅保存元数据。工具事件从结构化记录读取。
3. 同步 Skill 的来源、筛选示例和限制。用真实线程验证标题与正文检索、proof、locate、read、close，并对同一线程同时存在 T3 和原生记录时的结果计数做回归。

每个阶段独立验收。第一阶段支持本机已验证的 orchestration v2 表结构。
